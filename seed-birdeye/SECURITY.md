# Política de seguridad
- Vulnerabilidades: repórtalas vía GitHub Security Advisories (pestaña Security → Report a vulnerability). NO abras issues públicos con detalles de seguridad.
- NUNCA incluyas API keys o claves privadas en issues, PRs o capturas.
- El proyecto no acepta dependencias con compilación nativa (C/Rust): decláralo en el reporte si tu propuesta la requiere.
- Rotación: si filtraste una key, revócala en el proveedor ANTES de reportar.
